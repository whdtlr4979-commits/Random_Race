# 랜덤 레이스

3D 달리기 레이스로 하는 랜덤 뽑기 게임입니다. 참가자 이름을 넣으면 숲과 언덕, 강을 지나는 구불구불한 코스를 캐릭터들이 달리고, 1등(또는 꼴등)으로 들어온 사람이 당첨됩니다.

## 기능

- **크로스컨트리 코스**: 헤어핀, S자 커브, 오르막·내리막, 강을 건너는 다리 2개가 있는 코스. 숲, 바위, 오두막, 관중, 결승 관중석
- **사실적인 달리기 동작**: 실제 달리기 보행 데이터를 단순화한 관절 곡선(골반·무릎·발목)으로 움직이고, 디딤발이 땅에 붙도록 골반 높이를 계산. 속도에 따라 조깅↔전력질주 자세가 섞이고, 팔·골반 반대 회전, 커브에서 안쪽으로 기울기
- **참가자 2~30명**: 한 줄에 한 명씩, 또는 쉼표로 구분해서 입력 (입력 내용은 브라우저에 저장됨)
- **당첨 기준**: 1등 당첨 / 꼴등 당첨, 당첨 인원 여러 명 가능
- **코스 길이**: 250m(약 25초) / 400m(약 35초) / 600m(약 50초)
- **랜덤 요소**: 출발 자리, 컨디션 변화, ⚡ 부스터, 💥 넘어짐, 막판 스퍼트. 오르막에서는 느려지고 내리막에서는 빨라지며, 선수들은 커브 안쪽 라인을 타고 서로 비켜 달림
- **연출**: 3·2·1 카운트다운, 추격·측면·항공·정면 앵글을 몇 초마다 바꾸는 중계 카메라, 결승선 카메라, 접전일 때 슬로모션(PHOTO FINISH), 실시간 순위표, 미니맵, 효과음
- **공정성**: 모든 참가자가 같은 확률 분포에서 `crypto.getRandomValues` 난수를 받습니다. 6명·400m로 3,000번 시뮬레이션했을 때 각 참가자의 1등 비율은 15.5~17.4%(기대값 16.7%)였습니다.
- PC와 모바일(세로 화면) 모두 지원

## 실행 방법

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 터미널에 표시된 주소(기본 http://localhost:5173)를 엽니다.

### 파일 하나로 빌드

```bash
npm run build
```

`dist/index.html` 파일 하나에 모든 코드가 들어갑니다. 서버 없이 더블클릭으로 열어도 실행됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.js` | 화면 전환, 카메라, 순위 HUD, 메인 루프 |
| `src/course.js` | 코스 중심선(직선·원호 조각), 고도, 강 위치 |
| `src/race.js` | 레이스 시뮬레이션 (속도, 경사, 주행 라인, 이벤트, 골인 판정) |
| `src/runner.js` | 3D 캐릭터와 관절 기반 달리기/넘어짐/세리머니 애니메이션 |
| `src/world.js` | 지형, 도로, 강과 다리, 숲, 관중, 아치, 하늘 |
| `src/confetti.js` | 색종이 파티클 |
| `src/audio.js` | WebAudio로 합성한 효과음 |
| `src/style.css` | UI 스타일 |
