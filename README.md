# 랜덤 레이스

3D 달리기 레이스로 하는 랜덤 뽑기 게임입니다. 참가자 이름을 넣으면 육상 트랙에서 캐릭터들이 달리고, 1등(또는 꼴등)으로 들어온 사람이 당첨됩니다.

## 기능

- **3D 경기장**: Three.js로 만든 육상 트랙, 관중석, 결승 아치, 그림자, 색종이 연출
- **참가자 2~30명**: 한 줄에 한 명씩, 또는 쉼표로 구분해서 입력 (입력 내용은 브라우저에 저장됨)
- **당첨 기준**: 1등 당첨 / 꼴등 당첨, 당첨 인원 여러 명 가능
- **코스 길이**: 60m / 100m / 160m
- **랜덤 이벤트**: 컨디션 변화, ⚡ 부스터, 💥 넘어짐, 막판 스퍼트
- **연출**: 3·2·1 카운트다운, 선수를 따라가는 중계 카메라, 결승선 카메라, 접전일 때 슬로모션(PHOTO FINISH), 실시간 순위표, 효과음
- **공정성**: 모든 참가자가 같은 확률 분포에서 `crypto.getRandomValues` 난수를 받습니다. 6명으로 6,000번 시뮬레이션했을 때 각 레인의 1등 비율은 15.8~17.5%(기대값 16.7%)였습니다.
- PC와 모바일(세로 화면) 모두 지원

## 실행 방법

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 터미널에 표시된 주소(기본 http://localhost:5173)를 엽니다.

### 파일 하나로 빌드

```bash
npm run build
```

`dist/index.html` 파일 하나에 모든 코드가 들어갑니다. 서버 없이 더블클릭으로 열어도 실행됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.js` | 화면 전환, 카메라, 순위 HUD, 메인 루프 |
| `src/race.js` | 레이스 시뮬레이션 (속도, 이벤트, 골인 판정) |
| `src/runner.js` | 3D 캐릭터 모델과 달리기/넘어짐/세리머니 애니메이션 |
| `src/world.js` | 하늘, 조명, 트랙, 관중석, 결승 아치 |
| `src/confetti.js` | 색종이 파티클 |
| `src/audio.js` | WebAudio로 합성한 효과음 |
| `src/style.css` | UI 스타일 |
